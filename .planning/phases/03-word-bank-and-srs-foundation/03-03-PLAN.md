**PROG-01 - Learned vs Unseen:**
- `getDueWords([{word:'new'}])` -> `[]` (no SRS state = unseen = NOT due)
- `getDueWords([{word:'past', srs:{nextReviewDate: past}}])` -> `[{word:'past',...}]` (has SRS + overdue = due)
- `getDueWords([{word:'future', srs:{nextReviewDate: future}}])` -> `[]` (has SRS but not yet due)

**PROG-03 - Jitter:**
- `addJitter(1)` -> `1` (no jitter for 1-day intervals)
- `addJitter(10)` -> value between 9 and 11 (10 +/- 10%)
- `addJitter(100)` -> value between 90 and 110 (100 +/- 10%)
- Result is always >= 1 and always an integer

**PROG-02 + PROG-04 - Session Builder:**
- `buildReviewSession(words, progress)` returns max 7 overdue words + max 3 low-rep words
- Overdue words sorted by nextReviewDate ascending (most overdue first)
- Unseen words (no progress entry) are NEVER included
- Total session max 10 words

**Jitter in calculateNextReview:**
- `calculateNextReview(state, quality)` applies jitter to nextReviewDate via addJitter
- Base `interval` field stays un-jittered (for algorithm continuity)
- `nextReviewDate` uses jittered interval
  </behavior>
