     verbs_transitive: [...],  // Keep hardcoded -- verbs have he_m/he_f forms
     verbs_intransitive: [...],  // Keep hardcoded
     objects: [...],  // Keep hardcoded
   };

<task type="auto">
  <name>Task 2: Audit and fix gender usage in ENCOURAGEMENT messages and NPC dialogues</name>
  <files>src/data/story.js</files>
  <action>
Audit every player-facing string in `story.js` for Hebrew gender correctness. The story already has boy/girl variants for `intro` and `completion` texts, but ENCOURAGEMENT and NPC dialogues are ungendered.

**ENCOURAGEMENT (lines ~413-452):**

Review each message and fix gender issues:

1. `correct` array: Check for gendered words. Most are gender-neutral ("!מעולה", "!נכון מאוד"). Fix `'אתה כוכב! ⭐'` -- change to gender-neutral `'!כוכב ⭐'` or restructure as `{ boy: 'אתה כוכב! ⭐', girl: 'את כוכבת! ⭐' }`.

2. `wrong` array: `'אתה יכול! 💫'` is masculine -- change to gender-neutral or add variant. `'כמעט! נסה שוב 💪'` uses masculine imperative "נסה" -- change to gender-neutral or provide variants.

3. `streak` messages: `'אתה מכונה! 🤖'` is masculine. `'אתה החכם הצעיר ביותר!'` is masculine. Fix each.

4. `lowLives`: `'התרכז!'` is masculine imperative. Fix.

5. `dailyReturn`: `'בוקר טוב, גיבור! ☀️'` is masculine. Fix.

**Approach for ENCOURAGEMENT:** Convert each message that contains gendered Hebrew to a `{ boy: '...', girl: '...' }` object. Messages that are already gender-neutral (like "!מעולה" or "!וואו") stay as plain strings. The consuming code must check `typeof msg === 'string' ? msg : msg[playerGender === 'boy' ? 'boy' : 'girl']`.

Alternatively, if the consuming code doesn't easily support objects, make ALL messages gender-neutral by removing gendered forms (preferred if most messages can be made neutral).

**Research-based recommendation:** Prefer gender-neutral rewrites where possible (remove "אתה/את", use imperative forms that work for both, or use non-gendered phrasings). Only use boy/girl objects for messages that genuinely can't be made neutral. This minimizes code changes in consumers.
