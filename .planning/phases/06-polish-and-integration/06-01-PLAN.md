<task type="auto">
  <name>Task 1: Create WordBookScreen with category navigation and word cards</name>
  <files>src/components/screens/WordBookScreen.jsx</files>
  <action>
Create a new WordBookScreen component that lets players browse all words organized by category.

**Data derivation (do NOT duplicate logic):**
- Import `initialWordData` from `../../data/words`
- Import `WORD_CATEGORIES` from `../../data/wordSchema`
- Import `useGameStore` from `../../store/gameStore` and select `userProgress`
- Derive mastery band using the same thresholds as `challengeSelector.js`: repetition 0-1 = new, 2-3 = learning, 4-5 = familiar, 6+ = mastered. Write a local `getMasteryBand(repetition)` function matching those thresholds.

**Component structure:**
- Props: `{ onClose }` (called to return to start screen)
- State: `activeCategory` (string, defaults to first category with learned words, or `WORD_CATEGORIES[0]`)
- Category tabs: horizontal scrollable row of buttons, one per WORD_CATEGORIES entry. Show category emoji + Hebrew name + count of learned words in that category. Active tab highlighted with ring/bg color.
- Category Hebrew names mapping: animals=חיות, food=אוכל, family=משפחה, colors=צבעים, nature=טבע, body=גוף, actions=פעולות, home=בית, emotions=רגשות, professions=מקצועות
- Word cards: for the active category, filter `initialWordData` by `w.category === activeCategory`. For each word, render a card showing:
  - Word emoji + English word (bold)
  - Hebrew translation
  - Mastery badge: colored dot/label based on mastery band (unseen=gray, new=blue, learning=yellow, familiar=orange, mastered=green)
  - Expandable detail (use local useState per card or a single `expandedWordId` state): when tapped, show hint (use gendered hint if available, fallback to neutral), exampleSentence (English), exampleSentence_he (Hebrew)
- Unseen words (no entry in userProgress): show with emoji and word visible but grayed out, no detail expand. This creates discovery motivation.
- Performance: only render cards for the active category (10-25 words), not all 201 at once. Use `motion.div` only on active card list, not each card.

**Styling:**
- Full-screen layout with motion.div wrapper (initial/animate/exit opacity pattern matching other screens)
- Exit button top-left ("← מילון" text, purple-600 like MemoryGame exit button)
- Category tabs: `overflow-x-auto flex gap-2 pb-2` for horizontal scroll
- Word cards: white bg, rounded-2xl, shadow-sm, p-4, stacked vertically with gap-3
- Mastery colors: unseen=#94a3b8 (slate-400), new=#3b82f6 (blue-500), learning=#eab308 (yellow-500), familiar=#f97316 (orange-500), mastered=#22c55e (green-500)

**Do NOT:**
- Import or call getMasteryBand from challengeSelector.js (it's not exported). Recreate the same logic locally.
- Show SRS numbers directly (repetition, interval). Only show the band label.
- Use framer-motion on individual cards (performance concern with 20+ cards). Only use it on the container/category transition.
