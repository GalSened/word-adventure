**srs.test.js** — Test `calculateNextReview` and `getDueWords`:

Use `vi.useFakeTimers()` and `vi.setSystemTime(new Date('2025-01-01'))` in a `beforeEach` to make `Date.now()` deterministic. Restore with `vi.useRealTimers()` in `afterEach`.

Tests for `calculateNextReview`:
- First successful review (null previousState, quality=5): interval=1, repetition=1
- First successful review (null previousState, quality=3): interval=1, repetition=1 (minimum passing quality)
- Second successful review (interval=1, rep=1, ef=2.5, quality=4): interval=6, repetition=2
- Third successful review (interval=6, rep=2, ef=2.5, quality=4): interval=Math.round(6*2.5)=15, repetition=3
- Failed review (quality=2): repetition resets to 0, interval=1 regardless of previous state
- Failed review (quality=0, blackout): repetition=0, interval=1
- Ease factor floor: repeated quality=0 reviews should not push easeFactor below 1.3
- Ease factor calculation: quality=5 should increase easeFactor (verify exact formula: ef + 0.1 - (5-q)*(0.08+(5-q)*0.02) → for q=5: ef+0.1)
- nextReviewDate: should equal Date.now() + interval * 86400000 (for a known fake time)

Tests for `getDueWords`:
- Words with no `srs` property are always due (returns them)
- Words with `nextReviewDate` in the past are due
- Words with `nextReviewDate` in the future are NOT due
- Empty array returns empty array
- Mixed array returns only due words

**grammarEngine.test.js** — Test `generateChallenge`:

Use `vi.spyOn(Math, 'random')` to make output deterministic. Restore with `vi.restoreAllMocks()` in `afterEach`.

The function calls `getRandom` which does `arr[Math.floor(Math.random() * arr.length)]`. To select index 0 from any array, return 0.0. To select the last element of an array with N items, return a value just below 1.0 like (N-1)/N + 0.001.

The call sequence is: (1) select template, (2) within template.generate(), select noun, then select adjective/verb/object depending on template.

Tests for template 1 (Subject + Adjective) — mock Math.random to return 0.0 for all calls:
- Template 0 selects first noun (CAT, 'm') and first adjective (BIG)
- English: "THE CAT IS BIG"
- Hebrew: "החתול גדול" (masculine form he_m)
- Type is 'sentence', level is 'master'

Test gender agreement (feminine) — mock to select template 0, noun index 5 (PRINCESS, 'f'), adjective index 0 (BIG):
- Math.random sequence: 0.0 (template 0), 5/10=0.5 (noun PRINCESS), 0.0 (adj BIG)
- Hebrew should use he_f: "הנסיכה גדולה"

Tests for template 2 (Subject + Intransitive Verb) — mock to select template index 1:
- Math.random sequence: 1/3≈0.334 (template 1), 0.0 (noun CAT), 0.0 (verb SLEEPS)
- English: "THE CAT SLEEPS"
- Hebrew: "החתול ישן" (masculine)

Test template 2 feminine — select PRINCESS + SLEEPS:
- Hebrew: "הנסיכה ישנה" (feminine)

Tests for template 3 (Subject + Transitive Verb + Object) — mock to select template index 2:
- Math.random sequence: 2/3≈0.667 (template 2), 0.0 (noun CAT), 0.0 (verb LOVES), 0.0 (obj THE BALL)
- English: "THE CAT LOVES THE BALL"
- Hebrew: "החתול אוהב את הכדור"

Test return shape:
- Has `id` starting with "gen_"
- Has `word`, `hebrew`, `hint`, `level`, `type` properties
- `level` is always 'master'
- `type` is always 'sentence'

- Returns parsed object when valid JSON stored

- Returns parsed integer from string
