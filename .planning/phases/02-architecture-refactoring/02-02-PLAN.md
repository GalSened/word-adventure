  <action>
Create `src/context/GameContext.jsx`:

```jsx
import { createContext, useContext } from 'react';
import { useGameStore } from '../store/gameStore';

const GameContext = createContext(null);

export function GameProvider({ children }) {
  const store = useGameStore();
  return (
    <GameContext.Provider value={store}>
      {children}
    </GameContext.Provider>
  );
}

export function useGame() {
  const ctx = useContext(GameContext);
  if (!ctx) throw new Error('useGame must be used within GameProvider');
  return ctx;
}
```

This is intentionally minimal. The GameProvider re-exports the entire Zustand store through React Context. Components can use either `useGame()` (context) or `useGameStore(selector)` (direct Zustand) — both access the same underlying store.

Do NOT wrap WordAdventure in GameProvider yet — that happens in Plan 02-03 when the component is decomposed. This plan only creates the context file and rewires hooks.
