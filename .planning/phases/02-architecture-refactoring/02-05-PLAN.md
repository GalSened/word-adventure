This is a wiring task. The Zustand store (src/store/gameStore.js) already has all slices with all state and actions. The hooks (useGameState, useUserProgress, useDailyStats, useItemEffects) are already thin wrappers around useGameStore. The goal is to make WordAdventure use the store instead of local state.

**Step 1: Rewrite useGameLogic to read from Zustand store directly**

useGameLogic currently receives ~30 destructured props (state + setters). Rewrite it to:
- Import and call useGameStore at the top of the hook for reactive state
- Use useGameStore.getState() inside callbacks for mutations
- Remove ALL parameters from the function signature EXCEPT: `{ story, itemEffects }` (these are non-store hooks that must still be passed in, plus `setTranscript` from voice)
- So the new signature is: `useGameLogic({ story, itemEffects, setTranscript })`
- Inside the hook body, read persisted state via: `const { userProfile, score, stars, userProgress, avatar, highScores, inventory, dailyStats } = useGameStore()`
- Read ephemeral state via: `const { gameState, currentWordIndex, userInput, lives, feedback, activeWords, gameMode, activePet, currentStreak, currentLevel } = useGameStore()`
- For all mutations, use useGameStore.getState() to get setters and call them. Example: replace `setScore(s => s + earnedScore)` with `useGameStore.getState().addScore(earnedScore)` (using store actions where available) or direct setter calls like `useGameStore.getState().setGameState('playing')`
- Remove the `saveHighScore` local function — use `useGameStore.getState().saveHighScore(finalScore)` from the store's createUserSlice
- Remove the `handleAvatarSelect` direct localStorage call — use `useGameStore.getState().updateAvatar(icon)` instead of `localStorage.setItem(STORAGE_KEYS.AVATAR, icon)`
- Remove the `safeSetJSON` import and all its usages (the highScores save in saveHighScore)
- The `updateDailyStats` local function should use `useGameStore.getState().updateDailyStats({...})` from createDailySlice

**Step 2: Rewrite WordAdventure.jsx as a thin orchestrator**

Replace the entire component body. The new WordAdventure should:

1. **Imports:** Import useGameStore from store/gameStore, keep WelcomeScreen, StoryDialogue, StoryPathChoice, PetEvolution, StoryIntro, ScreenRouter, useVoiceRecognition, useStoryProgress, useItemEffects, useGameLogic, initialWordData. Remove safeGetJSON, safeSetJSON, safeGetNumber, STORAGE_KEYS imports.

2. **Persisted state from store (one call):**
   ```js
   const { userProfile, setUserProfile, score, avatar, inventory, dailyStats, stars } = useGameStore();
   ```

3. **Ephemeral state from store (one call):**
   ```js
   const { gameState, setGameState, currentStreak, activePet, lives, feedback, userInput, setUserInput, gameMode, activeWords, showStoryIntro, setShowStoryIntro, hasSeenStoryIntro, setHasSeenStoryIntro } = useGameStore();
   ```
   Note: `showStoryIntro` should be initialized from `!hasSeenStoryIntro` in the store. The game slice already has `showStoryIntro` but its default is `false`. The current code initializes it from `!safeGetJSON('hasSeenStoryIntro', false)`. After migration, the store persists `hasSeenStoryIntro` (boolean). WordAdventure can derive `showStoryIntro` from `!hasSeenStoryIntro` or use the ephemeral showStoryIntro from the game slice. The simplest approach: derive it inline: `const showStoryIntro = !useGameStore((s) => s.hasSeenStoryIntro);`

4. **Hooks:** Keep voice, story, itemEffects, logic — but pass minimal args to useGameLogic:
   ```js
   const voice = useVoiceRecognition();
   const story = useStoryProgress(userProfile);
   const itemEffects = useItemEffects(inventory);
   const logic = useGameLogic({ story, itemEffects, setTranscript: voice.setTranscript });
   ```

5. **Remove ALL 6 useEffect persistence blocks** (lines 52-63 in current file). Zustand persist middleware handles all persistence. The daily stats reset logic (checking if date changed) is already in useDailyStats hook's useEffect — but WordAdventure also has it. Since useDailyStats is not called directly by WordAdventure (it's in the store), add a single useEffect for daily reset:
   ```js
   useEffect(() => {
     if (dailyStats.date !== new Date().toDateString()) {
       useGameStore.getState().resetDailyStats();
       useGameStore.getState().setCurrentStreak(0);
     }
   }, [dailyStats.date]);
   ```
   Actually, check: useDailyStats hook already has this exact useEffect. If a screen or component uses useDailyStats(), this runs. But since WordAdventure reads dailyStats from the store now, and the store persists it, the reset MUST happen somewhere on mount. Keep this one useEffect for now (it ensures reset on app load). This is 4 lines.

6. **Remove the voice transcript useEffect** (line 63 in current file). Instead, keep it as a minimal useEffect:
   ```js
   useEffect(() => { if (voice.transcript) setUserInput(voice.transcript.toUpperCase().replace('.', '').replace('?', '').trim()); }, [voice.transcript]);
   ```

7. **WelcomeScreen guard:** Keep the early return: `if (!userProfile) return <WelcomeScreen onComplete={(profile) => setUserProfile(profile)} />;`

8. **screenProps object:** Build it from store values + hook returns. This is the same as current but reading from store variables. Since useGameLogic now reads state internally, many of the screenProps values come from the store directly:

   ```js
     gender: userProfile.gender, memoryWords: activeWords.length > 0 ? activeWords : initialWordData.slice(0, 12),
   };
   ```

9. **JSX:** Keep identical structure (background blobs, nav bar, ScreenRouter, StoryIntro, StoryPathChoice, StoryDialogue, PetEvolution). For the StoryIntro onComplete, use: `() => { setShowStoryIntro(false); useGameStore.getState().setHasSeenStoryIntro(true); }` — but wait, we derived showStoryIntro from !hasSeenStoryIntro, so just call `setHasSeenStoryIntro(true)` and the derivation handles the rest. Simplify: `onComplete={() => useGameStore.getState().setHasSeenStoryIntro(true)}`
