```javascript
export const CHALLENGE_TYPES = {
    SPELLING: 'spelling',

    REVERSE_CHOICE: 'reverseChoice',
    LISTENING: 'listening',
    SENTENCE_BUILD: 'sentenceBuild',
    GRAMMAR: 'grammar',
};
```

**2. Create src/utils/challengeSelector.js:**

Export a `selectChallengeType(word, srsState, recentTypes)` pure function:

- Define CHALLENGE_POOLS mapping mastery bands to allowed challenge types:
  - `new` (rep 0-1): `['multipleChoice', 'reverseChoice']`
  - `learning` (rep 2-3): `['multipleChoice', 'reverseChoice', 'listening']`
  - `familiar` (rep 4-5): `['reverseChoice', 'listening', 'spelling']`
  - `mastered` (rep 6+): `['spelling', 'sentenceBuild', 'listening']`

- Filter out `'sentenceBuild'` if `word.type !== 'sentence'` (currently no sentence-type words exist, but future-proof this).

- If `recentTypes` array is non-empty, filter out the last element from the pool to avoid consecutive same-type challenges. Only filter if it leaves at least 1 option.

- Return a random pick from the remaining pool using `Math.random()`.

- Export both `selectChallengeType` and `CHALLENGE_POOLS` (pools exported for testing).

**3. Create src/utils/distractorGenerator.js:**

Export a `generateDistractors(correctWord, count = 3, field = 'word')` function:

- Import `initialWordData` from `../data/words`.
- Filter out the correct word by id.
- Split remaining words into same-category and different-category pools.
- Shuffle each pool using Fisher-Yates (inline helper, same pattern as useGameLogic's shuffleArray).
- Take distractors preferring same-category first, filling from other-category if needed.
- Return array of `count` word objects (full word objects, not just strings -- caller decides which field to display).
- If fewer than `count` words available (shouldn't happen with 201 words), return what's available.

Also export a `shuffleArray(array)` utility (extracted from useGameLogic pattern) since it's needed in multiple places.

<task type="auto">
  <name>Task 2: Create MultipleChoice, ReverseChoice, and Listening challenge components</name>
  <files>src/components/challenges/MultipleChoiceChallenge.jsx, src/components/challenges/ReverseChoiceChallenge.jsx, src/components/challenges/ListeningChallenge.jsx</files>
  <action>
Create `src/components/challenges/` directory and three challenge components. All challenge components receive the same props interface:

```
{ word, onAnswer, disabled, playerGender, t }
```

Where `word` is the full word object, `onAnswer(isCorrect)` reports the answer, `disabled` prevents input during feedback, `playerGender` is 'boy'|'girl', and `t(male, female)` is the gender-aware text helper.

**1. MultipleChoiceChallenge.jsx (CHAL-02):**

- Import `generateDistractors` from `../../utils/distractorGenerator`.
- Import `motion` from `framer-motion` and `hapticFeedback` from `../../utils/mobile`.
- Use `useMemo` keyed on `word.id` to generate 4 options: correct word + 3 distractors, shuffled.
- Options show ENGLISH text (`word.word` field). Prompt shows HEBREW (`word.hebrew`).
- Instruction text (RTL): `{t('בחר', 'בחרי')} את התרגום הנכון`
- Display Hebrew word in large text (text-6xl), then a 2x2 grid of option buttons.
- Each button: `motion.button` with `whileTap={{ scale: 0.95 }}`, gradient blue styling, rounded-2xl, font-bold text-lg.
- On click: call `hapticFeedback(isCorrect ? 'success' : 'error')` then `onAnswer(isCorrect)`.
- When `disabled`, buttons show `opacity-50` and ignore clicks.

**2. ReverseChoiceChallenge.jsx (CHAL-03):**

- Same structure as MultipleChoiceChallenge but REVERSED direction.
- Prompt shows ENGLISH word (`word.word`) in large text.
- Options show HEBREW text (`word.hebrew` for correct, `distractor.hebrew` for wrong).
- Instruction: `{t('בחר', 'בחרי')} את התרגום הנכון`
- Pass `field='hebrew'` concept: when building options, each option is `{ text: w.hebrew, isCorrect: boolean }`.
- Use green gradient styling to visually distinguish from MultipleChoice.

**3. ListeningChallenge.jsx (CHAL-04):**

- Import `speakWord, isSpeechSupported` from `../../utils/speech`.
- Import `Volume2` from `lucide-react`.
- On mount (`useEffect` with `[word.id]` dependency), call `speakWord(word.word)` if supported.
- Show a large speaker button (Volume2 icon, size 48, blue-500 bg, rounded-full, p-6) that replays the word on click.
- If speech not supported, show the English word as text fallback (per pitfall #2 from research).
- Show 4 English text options (same as MultipleChoice) in a 2x2 grid.
- Use purple gradient styling.
- Instruction: `{t('הקשב ובחר', 'הקשיבי ובחרי')} את המילה הנכונה`

All components follow project conventions: default export function ComponentName, JSDoc header comment, React import, destructured props.
