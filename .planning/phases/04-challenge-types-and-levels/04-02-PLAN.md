  <files>src/components/challenges/SentenceBuildChallenge.jsx</files>
  <action>
Create `src/components/challenges/SentenceBuildChallenge.jsx` for CHAL-05.

**Props interface:** `{ word, onAnswer, disabled, playerGender, t }` -- same as all challenges.

For sentence building, `word.word` contains the correct English sentence (e.g., "THE CAT IS BIG"). The challenge splits this into individual words, shuffles them, and the player reorders them.

**Implementation:**

1. Import `Reorder, motion` from `framer-motion` and `hapticFeedback` from `../../utils/mobile`.

2. Use `useMemo` keyed on `word.id` to create initial shuffled items:
   - Split `word.word` by spaces.
   - Create unique item objects: `{ id: \`\${word}_\${index}\`, text: word }` to handle duplicate words (per pitfall #1 from research -- e.g., "THE CAT SEES THE DOG" has "THE" twice).
   - Shuffle the items array.

3. Store items in `useState(initialItems)`.

4. Render:
   - Instruction: `{t('סדר', 'סדרי')} את המשפט` (RTL)
   - Show Hebrew prompt: `word.hebrew` in text-4xl
   - `Reorder.Group` with `axis="x"`, `values={items}`, `onReorder={setItems}`
     - Use `className="flex flex-wrap gap-2 justify-center min-h-[60px] p-4 bg-white border-4 border-slate-100 rounded-2xl mb-4"` and `as="div"`
   - Each `Reorder.Item` with:
     - `key={item.id}`, `value={item}`
     - Yellow gradient styling: `px-4 py-3 bg-gradient-to-b from-yellow-300 to-yellow-400 text-yellow-800 rounded-xl font-bold text-xl cursor-grab shadow-md select-none`
     - `whileDrag={{ scale: 1.1, boxShadow: '0 10px 30px rgba(0,0,0,0.2)' }}`
     - `style={{ position: 'relative' }}` (needed for Reorder z-index)
     - Display `item.text`
   - Submit button: `motion.button` with `whileTap={{ scale: 0.95 }}`, purple-to-pink gradient, full width, py-4, rounded-2xl, disabled when `disabled` prop is true.
     - Button text: `{t('בדיקה', 'בדיקה')}`

5. `handleSubmit`: Extract text from items with `items.map(i => i.text).join(' ')`, compare with `word.word` (both `.toUpperCase()`). Call `hapticFeedback` then `onAnswer(isCorrect)`.

**Important:** This challenge is only appropriate for multi-word content. The adaptive selector (Plan 01) already filters `sentenceBuild` out when `word.type !== 'sentence'`. For now, this component works with any word object that has multi-word content -- it will be used with grammar-generated sentences.

**1. Create src/components/challenges/GrammarChallenge.jsx (CHAL-06):**

Grammar challenges use `generateChallenge()` from `grammarEngine.js` which produces objects like:
```
{
  id: 'gen_xxx',
  word: 'THE DOG IS BIG',
  hebrew: 'הכלב גדול',
  hint: '...',
  type: 'sentence',
  level: 'master'
}
```

The grammar challenge presents this as a multiple-choice question where the player picks the correct Hebrew translation from 4 options.

**Props interface:** `{ word, onAnswer, disabled, playerGender, t }` -- but `word` here is the grammar-generated challenge object passed from the game logic.

Since the grammar challenge word is pre-generated (not from the word bank), we need to generate distractors differently. Generate 3 more grammar challenges using `generateChallenge()` and use their Hebrew translations as wrong answers.

Implementation:
- Import `generateChallenge` from `../../utils/grammarEngine`.
- Import `motion` from `framer-motion` and `hapticFeedback` from `../../utils/mobile`.
- Use `useMemo` keyed on `word.id` to:
  - Generate 3 additional grammar challenges via `generateChallenge()`.
  - Build 4 options: `{ text: word.hebrew, isCorrect: true }` + 3 distractors `{ text: gen.hebrew, isCorrect: false }`.
  - Shuffle options.
  - If any distractor has the same Hebrew text as the correct answer (unlikely but possible), regenerate that distractor.

- Render:
  - Instruction: `{t('בחר', 'בחרי')} את התרגום הנכון` (same as multiple choice)
  - Show English sentence: `word.word` in text-3xl (smaller than word challenges since sentences are longer)
  - 2x2 grid of Hebrew options with emerald/teal gradient styling to visually distinguish grammar challenges.
  - On click: haptic feedback + `onAnswer(isCorrect)`.

**2. Create src/components/challenges/SpellingChallenge.jsx (CHAL-01):**

This wraps the existing `LetterPicker` component to conform to the challenge interface contract.

Props interface: `{ word, onAnswer, disabled, playerGender, t }` plus additional props needed by LetterPicker: `scrambledContent, userInput, setUserInput`.

The SpellingChallenge is unique because it requires more props than the standard interface -- `scrambledContent`, `userInput`, and `setUserInput` are managed by `useGameLogic` and must be passed through. The `onAnswer` callback is not used directly; instead, LetterPicker calls `onCheck` which triggers `handleCheck` in useGameLogic (which itself calls `processAnswer`).

Implementation:
- Import LetterPicker from `../LetterPicker`.
- Import `speakWord, isSpeechSupported` from `../../utils/speech` and `hapticFeedback` from `../../utils/mobile`.
- Import `Volume2` from `lucide-react`.
- Receive extended props: `{ word, onAnswer, disabled, playerGender, t, scrambledContent, userInput, setUserInput, onCheck }`.
- Compute gender-aware hint using the same fallback chain as current PlayingScreen: `hint_m` for boys, `hint_f` for girls, `hint` as neutral default.
- Render the same content currently in PlayingScreen's challenge card:
  - Instruction: `{t('תרגם', 'תרגמי')} את ה{word.type === 'sentence' ? 'משפט' : 'מילה'}`
  - Hebrew word display (text-6xl) with optional speaker button (same as current PlayingScreen).
  - Gender-aware hint paragraph.
  - `<LetterPicker>` with `key={word.id}`, `letters={scrambledContent}`, `currentInput={userInput}`, `setCurrentInput={setUserInput}`, `onCheck={onCheck}`, `isWord={word.type !== 'sentence'}`, `disabled={disabled}`.

This extracts the challenge rendering from PlayingScreen into a standalone component, making PlayingScreen a thin shell (lives + feedback overlay + ChallengeDispatcher).
